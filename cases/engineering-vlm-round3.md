# VLM 第三轮：局部识别与整页替代对照

本轮完成同机 PP-OCR 基线／公差流程对照，以及两个预训练 VLM 的局部、整页与重复测试。结果仍为开发集证据；不自动采用候选、不把待复核计为正确、不将现有 20 页重新包装成独立验收集。

## 固定输入与实际配置

- 20 张真实图纸、238 个预选区域：机械 118、P&ID 120；[原始来源](../artifacts/real-drawings-20261008/SOURCES.md)。原图和旧报告保留，VLM 不读取原 OCR 或参考答案。
- 118 条诊断用途有一个裁剪同时用于直径与公差：合并成 117 次唯一推理，保留两种用途。Paddle 已执行结果仅作可审计的清单去重映射，原始输出逐文件字节不变；Qwen 直接使用唯一队列。
- 每个 VLM 397 个唯一正式任务，两模型合计 794 次。另有同机 PP-OCR 正式请求 100 次、预热 8 次；初始化试跑、加载排障和复试单独保留，不混入正式分数。
- 主机通过 `nvidia-smi` 报告 RTX 4080 SUPER、32760 MiB、驱动 595.71.05、计算能力 8.9。这是平台可见设备信息；不推断其物理显存配置。不是上一轮 RTX 5090 的原硬件，性能比较使用本轮同机基线。
- Paddle：原生 PaddleOCRVL v1.6，BF16，PP-DocLayoutV3，Paddle GPU 3.3.1、PaddleOCR 3.7.0、PaddleX 3.7.2。Qwen：BF16、SDPA、torch 2.8.0、transformers 4.57.6。两个环境隔离、模型串行运行。
- 外部像素上限局部 1,048,576／整页 4,194,304；输出上限 512／8192 token；单请求超时 300 秒，加载上限 600 秒。实际缩放尺寸、内部图像网格及 token 统计见[输入记录](../artifacts/engineering-vlm-round3-20261008/input-transforms.jsonl)。不能把内部缩放差异归因于纯模型能力。
- Paddle 使用原生 `OCR:`／表格模板，Qwen 使用冻结的逐字转写／带坐标 JSON 指令，提示词身份随记录保存。比较的是两种冻结处理方案，非完全相同提示词消融。
- token 上限的作用范围不同：Qwen 限制每次整图生成，Paddle 限制每个原生识别调用，整页可能包含多个布局块调用；Paddle 任一调用截断都会将该页记为截断。原生调用数和各次 token 观测单独保留，不把这个上限描述成相同的整页总输出预算。

实际权重固定到官方仓库提交：[PaddleOCR-VL-1.6](https://huggingface.co/PaddlePaddle/PaddleOCR-VL-1.6/tree/c5630abae1d940eafe0697512a0325494b02ab42)、[Qwen3-VL-8B-Instruct](https://huggingface.co/Qwen/Qwen3-VL-8B-Instruct/tree/0c351dd01ed87e9c1b53cbc748cba10e6187ff3b)。权重文件、布局模型和配置摘要见[审计记录](../artifacts/engineering-vlm-round3-20261008/audit.json)。官方通用榜单分数不代替工程图验收。

这些裁剪位置预先已知，不能作为整页自动识别准确率。只规范空白，保留大小写和 Unicode；LaTeX、下划线等格式输出也不在事后偷偷折叠成正确答案。构造反例覆盖空集、O／0、真实负号、正号、正负号、直径、图线和独立相邻数字，不与真实图纸混分。

相对同机 OCR 原文，固定裁剪中 Paddle 有 14 个由错变对、14 个由对变错；Qwen 有 18 个由错变对、11 个由对变错。这里包含预先裁剪带来的定位优势，不能当作替换生产流程后的净增益。[逐项配对编号与反例输出](../artifacts/engineering-vlm-round3-20261008/summary.json)同时保留正反变化。

Qwen 的 11 个退步均在机械区域，其中 6 个出现额外横线／负号，例如 `12.41 → 12.41 -`、`6X R.25 → - 6X R.25`。还有旋转数字次序或漏位错误。构造反例没有新增关键符号并不能排除真实图线的误补；因此没有满足“局部增益且无已知新增误补”的接入条件，保留离线人工复核实验，不接入生产自动复核调度。

候选命中另列：两种 VLM 的候选池中，机械 98/118、P&ID 119/120 曾出现完整正确值；再包含原 OCR，机械为 101/118。这是使用参考答案检查候选是否存在的上界，不是能在未知图纸上自动选对答案的准确率，也没有加入正式原文成绩。

## 整页：位置与结构合同

| 相同固定区域和匹配规则 | 原 PP-OCR 工程流程 | Paddle 整页 | Qwen 整页 |
|---|---:|---:|---:|
| 机械完整转写与类型／位置 | 83/118 | 0/118 | 0/118 |
| P&ID 完整转写与类型／位置 | 113/120 | 0/120 | 0/120 |
| D060322 进入有效单元格 | 10/10 | 0/10 | 0/10 |
| 整页运行／解析失败 | 0/20 | 10/20 | 10/20 |
| 正常返回但无可评分文字区域 | 0/20 | 2/20 | 10/20 |
| 页面仍待复核 | 20/20 | 20/20 | 20/20 |

保持 IoU ≥0.2、一对一和 `line/cell` 类型匹配。输出截断、超时、退出或解析失败的页面按零识别信用处理，原生输出仍保留。Paddle 原生结果包含整块图形／段落文本，但不提供其中每条尺寸的独立框；HTML 表格也没有目标单元格坐标，其中 2 页只有这类表格输出，适配后无可评分文字区域。因此严格项目得分低不能解读为“模型完全没读出文字”。适配器没有拆出虚假的行框，也没有取消单元格类型要求。Qwen 的预测框与 Paddle 的检测器块框分别标记来源。

Paddle 的初始异步 CUDA 试跑曾超时；正式试验显式设置 `CUDA_LAUNCH_BLOCKING=1` 并保留这一性能条件。正式试验还开启了 60 秒诊断堆栈抓取，部分退出紧随异常堆栈输出，未发现 cgroup OOM 记录；退出原因未确认，不能断言为显存不足或纯模型失败。后续关闭诊断抓取的复试单列，不覆盖首次失败。

|---|---|---|
| `page-johannesburg-11` | worker_exited / 60.28 秒 | output_truncated / 247.99 秒 |

## 公差流程、证据与校对

分行扩展裁剪尊重上下偏差和单元格边界，再按实际识别出的符号生成组合候选。`.048 +.002 -.003` 可形成候选；`1.046 +.003 -.002` 仍缺直径，不能计作完整正确。原有几何关联可能将邻近 `1.13` 与偏差误关联，所以关联不直接放行。新增流程在全部 20 页没有改变普通／工程模式原文分数，未新增已知文字或零件表回归。

VLM 结果保存原始输出、任务与裁剪摘要、位置、实际模型、提示词和失败状态。证据附加遵循唯一位置匹配，未知匹配明确留存；首次转写不变。接口／后台任务与 JSON 文件导出沿用原有审计位置和 `review` 状态。

本地校对页面提供原图定位、裁剪、参考和两个模型候选，支持人工修改及标注导入／导出。没有把 VLM 生成内容当作真值；目前没有新增人工确认。训练导出要求许可证据、两名不同校对者的一致确认，以及明确核验的图纸家族映射；图号不能自动视为独立家族，未核验映射和跨集合家族均阻止导出。因此当前训练真值导出为 0。

## 耗时与边界

同机 PP-OCR 工程模式的完整 HTTP JSON 请求：机械旧流程 P50/P95 为 20.09/24.19 秒，公差改进后 21.02/24.85 秒；P&ID 为 44.64/55.13 秒与 46.68/57.99 秒。两组各 20 页，无请求失败；整卡采样峰值均为 5606 MiB。复核预算仍为 128 区域／45 秒，实际检查 2094/3817 个唯一目标，1641 个目标因复核预算未完成，12/20 页存在预算耗尽。分组数值及同页重复请求另存，未用单次跨页差异推断稳定加速。

## 路线选择

保留 PP-OCR 工程流程为默认；两个 VLM 整页方案均需先满足机械高于 83/118、P&ID 不低于 113/120，并无已知定位／表格回归，才能进入替代候选。局部候选有增量也必须检查新增错误，不能用“候选池出现过答案”代替最终准确率。此次保留 VLM 为可人工核查的实验入口，未启用自动覆盖或自动通过。

下一阶段以本轮失败分类整理训练材料：区分直径字形、负号／小数点、完整公差、原生输出格式和定位结构问题；先补足许可及独立人工标签，再决定专项微调。最终验收另建按图纸家族隔离的新集，关键符号 ≥99%、完整标注 ≥95% 仍是目标。

样本规范保留完整原图、裁剪框、方向、上下文与字符原始 Unicode；直径与空集、真实负号与图线成对收集，旋转数字保留未经校正图和校正视图，公差同时标完整标注与各片段。每例记录图纸家族、许可、人工校对状态和模型错误类型。同一图纸及其裁剪不能跨调参与验收集合，VLM 只贡献候选和错误清单，不贡献自动真值。现已整理 77 条模型错误候选记录（Paddle 42、Qwen 35，可能指向同一区域），启发式分类只供人工复核，不作为已确认根因。
